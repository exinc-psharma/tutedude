# Responsive Laundry Service Landing Page with Hamburger Menu

## Description

This project was created as part of the TuteDude Frontend Development assignment. It builds upon the previous responsive laundry service landing page by introducing a mobile hamburger menu, CSS pseudo-classes, interactive navigation elements, and improved user experience across different screen sizes.

## Features

* Responsive layout using Flexbox
* Desktop, tablet, and mobile views
* Mobile hamburger menu
* Slide-in navigation panel for small screens
* CSS transition animations
* Interactive navigation links
* Clickable logo and navigation menu
* Responsive hero section with image and call-to-action button
* Hover and active state effects

## Improvements Over Previous Assignment

### Navigation Enhancements

* Converted navigation items into proper anchor (`<a>`) elements.
* Made the logo clickable so it can return users to the top of the page.
* Structured navigation links to support future page section navigation.

### Mobile Hamburger Menu

* Added a hamburger menu button visible only on mobile devices.
* Implemented a slide-in navigation panel using CSS.
* Used the `:focus` pseudo-class to control menu visibility without JavaScript.
* Added smooth transition animations for improved user experience.

### User Interaction

* Hover effects on navigation links.
* Hover effects on the logo.
* Hover effects on buttons and username badge.
* Active-state styling for navigation interactions.

### Responsive Design

* Tablet-specific adjustments for typography and image sizing.
* Mobile-specific layout using `flex-direction: column`.
* Responsive image scaling.
* Adaptive navigation behavior across screen sizes.

## How to Run

1. Download the project files.
2. Ensure `index.html` and `style.css` are located in the same folder.
3. Open `index.html` in a web browser.
4. Resize the browser window or use developer tools to test responsiveness.
