# JavaScript Number Even or Odd

## Description

A simple JavaScript program that checks whether a number is even or odd using the modulus (`%`) operator and `if-else` statements. The program demonstrates conditional logic by evaluating multiple variables and displaying the result in the browser console.

## Features

* Checks whether a number is even or odd
* Uses the modulus (`%`) operator
* Uses `if-else` conditional statements
* Demonstrates template literals for output formatting
* Displays results in the browser console
* Evaluates multiple variables independently

## JavaScript Concepts Used

* Variables (`const`)
* Arithmetic Operators (`%`)
* Comparison Operators (`==` / `===`)
* Conditional Statements (`if-else`)
* Template Literals
* Console Output (`console.log()`)

## How to Run

1. Open the project folder.
2. Open `index.html` in a browser.
3. Open Developer Tools (`F12`).
4. Go to the **Console** tab.
5. View the output showing whether each number is even or odd.

* HTML5
