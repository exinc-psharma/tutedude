# Task 5 - Laundry Services Hero Section

## Description

This project implements a modern hero section for a laundry service website. The design includes a navigation bar, branding elements, a call-to-action section, and an illustrative image.

## Features

* Navigation bar
* Logo section
* Username display
* Hero section layout
* Responsive viewport-based sizing
* Call-to-action button
* Image and text alignment
* Custom typography and colors

## How to Run

1. Download the project files.
2. Ensure `index.html` and `style.css` are located in the same folder.
3. Open `index.html` in any web browser.

## Technologies Used

* HTML5
* CSS3

## Notes

This project focuses on page layout, positioning, typography, and hero section design without using Flexbox.
