# Laundry Services Responsive Page

## Description

This project was created as part of the TuteDude Frontend Development assignment. It demonstrates the use of CSS Flexbox and Media Queries to create a responsive laundry service landing page that adapts to desktop, tablet, and mobile screen sizes.

## Features

* Responsive navigation bar
* Flexbox-based hero section layout
* Tablet-specific styling adjustments
* Mobile-friendly stacked layout using Flexbox
* Responsive image scaling
* Styled call-to-action button with hover effect
* Hidden navigation links on mobile devices
* Clean and user-friendly interface

## How to Run

1. Download the project files.
2. Ensure both `index.html` and `index.css` are in the same folder.
3. Open `index.html` in any modern web browser.
4. Resize the browser window or use developer tools to test desktop, tablet, and mobile responsiveness.

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Media Queries

## Responsive Design

### Desktop View
* Navigation links, logo, and username are displayed.
* Hero section is arranged horizontally with text and image side by side.

### Tablet View
* Text, image, logo, and navigation elements are resized appropriately.
* Layout remains horizontal while improving readability on smaller screens.

### Mobile View
* Navigation links are hidden.
* Only the logo and username badge remain visible in the navigation bar.
* Hero section changes to a vertical layout using `flex-direction: column`.
* Text content appears above the image for better mobile usability.

## Notes

This project was built according to the TuteDude assignment requirements and focuses on practicing responsive web design using Flexbox and Media Queries without using any CSS frameworks such as Bootstrap.
