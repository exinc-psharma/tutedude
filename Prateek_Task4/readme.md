# Task 4 - CSS Units, Box Model and Fonts

## Description

This project demonstrates the use of CSS viewport units, box model properties, and typography styling. The webpage contains an image section and a button styled according to the assignment requirements.

## Features

* Viewport units (vw and vh)
* CSS box model
* Image container styling
* Gradient button
* Border styling
* Responsive spacing

## How to Run

1. Download the project files.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in a browser.

## Technologies Used

* HTML5
* CSS3

## Notes

The layout uses viewport units to maintain proportional spacing across different screen sizes.
