JavaScript Loops Practice

---

# Description

This project demonstrates the use of JavaScript loops, conditional statements, and basic number-based algorithms. The program performs multiple operations on a given number, including calculating the sum of the first N natural numbers, printing the multiplication table, checking for prime numbers, finding factors, calculating the sum of digits, and checking whether the number is an Armstrong number.

---

# Features

- Calculate the sum of the first N natural numbers
- Print the multiplication table of N
- Check whether a number is Prime or Not Prime
- Find and display all factors of a number
- Calculate the sum of digits of a number
- Check whether a number is an Armstrong Number
- Uses both `for` and `while` loops
- Demonstrates conditional statements and arithmetic operators
