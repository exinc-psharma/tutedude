# JavaScript DOM and Event Handling

## Description

A simple interactive web page built using HTML, CSS, and JavaScript as part of the TuteDude Frontend Development course. This project demonstrates DOM manipulation and event handling by allowing users to change box colors and display a personalized greeting message.

## Features

* Header displaying a greeting message
* Four clickable color boxes (Red, Blue, Green, Yellow)
* Input field for entering a user's name
* Greet button to display a personalized greeting
* Dynamic DOM updates using JavaScript
* Color-changing boxes using click events
* Simple and clean centered layout

## How to Run

1. Download the project files.
2. Ensure all files are in the same folder:
   * `index.html`
   * `style.css`
   * `script.js`
3. Open `index.html` in a browser.
4. Enter a name and click the **Greet** button.
5. Click any color box to change its background color.
