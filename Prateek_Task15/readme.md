# JavaScript Arrays and Functions

## Description

A JavaScript program that performs multiple operations on an array using functions. The program finds the maximum number in the array, calculates the sum of all elements, and counts the number of odd numbers present in the array.

## Features

* Stores data using a JavaScript array
* Finds the maximum element in the array
* Calculates the sum of all array elements
* Counts the number of odd numbers in the array
* Uses separate functions for each operation
* Displays results using `console.log()`
* Uses template literals for formatted output

## JavaScript Concepts Used

* Arrays
* Arrow Functions
* Variables (`let`, `const`)
* Loops (`for`)
* Conditional Statements (`if`)
* Comparison Operators
* Arithmetic Operators
* Template Literals
* Function Return Values
* Console Output (`console.log()`)

## How to Run

1. Open the project folder.
2. Open `index.html` in a browser.
3. Open Developer Tools (`F12`).
4. Navigate to the **Console** tab.
5. View the output generated by the JavaScript program.
