# Laundry Services Hero Section – Hero Image Animation

## Description

This project was created as part of the TuteDude Frontend Development assignment. It enhances the previously built Laundry Services responsive landing page by adding an animated hero image using CSS keyframe animations, transforms, and scaling effects.

## Features

* Responsive Laundry Services landing page.
* Continuous orbit-style animation for the hero image.
* Counter-rotation effect to simulate an orbiting motion.
* Squash and stretch animation for added visual appeal.
* Smooth infinite animation using CSS keyframes.
* Interactive CTA button with hover effects.
* Responsive design for desktop, tablet, and mobile devices.
* Navigation links implemented using anchor tags.
* Clickable logo that can be used to navigate back to the top/home section.
* Hover and active states added for improved user interaction.

## CSS Concepts Used

* Flexbox
* Media Queries
* CSS Animations (`@keyframes`)
* CSS Transforms (`rotate`, `scale`)
* CSS Transitions
* Hover Pseudo-class (`:hover`)
* Active Pseudo-class (`:active`)
* Positioning (`relative`, `absolute`)
* Responsive Design Techniques

## How to Run

1. Download or clone the project files.
2. Ensure both `index.html` and `index.css` are in the same project folder.
3. Open `index.html` in any modern web browser.
4. Observe the animated hero image and interact with the page elements.
