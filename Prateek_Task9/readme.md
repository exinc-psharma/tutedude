# Laundry Services Hero Section – Button Hover Animation

## Description

This project was created as part of the TuteDude Frontend Development assignment. It enhances the previously built Laundry Services responsive landing page by adding interactive hover effects to the Call-To-Action (CTA) button using CSS transforms and transitions.

## Features

* Responsive Laundry Services landing page.
* Interactive CTA button hover animation.
* Button increases in size on hover using `scale()`.
* Button tilts on hover using `rotate()`.
* Smooth animations using CSS `transition`.
* Responsive design for desktop, tablet, and mobile devices.
* Navigation links implemented using anchor tags.
* Clickable logo that can be used to navigate back to the top/home section.
* Hover and active states added for improved user interaction.

## CSS Concepts Used

* Flexbox
* Media Queries
* CSS Transforms (`scale`, `rotate`)
* CSS Transitions
* Hover Pseudo-class (`:hover`)
* Active Pseudo-class (`:active`)
* Responsive Design Techniques

## How to Run

1. Download or clone the project files.
2. Ensure both `index.html` and `index.css` are in the same project folder.
3. Open `index.html` in any modern web browser.
4. Hover over the CTA button to view the animation effect.

## Technologies Used
