# Task 3 - CSS Selectors

## Description

This project demonstrates the use of various CSS selectors and styling techniques. The assignment focuses on understanding how CSS targets HTML elements using different selector types.

## Features

* Element selectors
* Class selectors
* ID selectors
* Pseudo-class selectors
* nth-child selector
* Text and background styling
* Link styling

## How to Run

1. Download all project files.
2. Ensure `style.css` and `index.html` are in the same folder.
3. Open `index.html` in a web browser.

## Technologies Used

* HTML5
* CSS3

## Notes

This project was created to practice CSS selector specificity and styling techniques.
