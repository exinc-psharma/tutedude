# Task 2 - Laundry Wallah / Laundry Mart

## Description

This project is a simple HTML webpage created for a laundry service business. The page provides information about services, pricing, booking details, and contact information.

## Features

* Welcome section
* About section
* Laundry image
* Services list
* Price table
* Booking form
* Contact information footer

## How to Run

1. Download the project files.
2. Open `index.html` in any web browser.

## Technologies Used

* HTML5

## Notes

This project demonstrates the use of forms, tables, lists, images, and semantic HTML structure.
