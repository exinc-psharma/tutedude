# Task 1 - Basic HTML Webpage

## Description

This project was created as part of the TuteDude Frontend Development course. The objective was to build a basic HTML webpage using fundamental HTML elements and proper document structure.

## Features

* HTML5 document structure
* Headings and paragraphs
* Images
* Lists
* Basic page content organization

## How to Run

1. Download the project files.
2. Open `index.html` in any modern web browser.

## Technologies Used

* HTML5

## Notes

This project focuses on learning the fundamentals of HTML and webpage structure.
