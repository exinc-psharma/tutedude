# Laundry Mart Login Page

## Description

This project was created as part of the TuteDude Frontend Development assignment. It demonstrates the use of HTML and CSS Flexbox to build a responsive login page with a split-screen layout.

## Features

* Split-screen layout using Flexbox
* Laundry-themed image section
* Styled login form with email and password inputs
* Login button with hover effects
* Register link and forgot password section
* Clean and modern user interface

## How to Run

1. Download the project files.
2. Ensure both `index.html` and `style.css` are in the same folder.
3. Open `index.html` in any modern web browser.

## Technologies Used

* HTML5
* CSS3
* Flexbox Layout

## Notes

This project was built according to the TuteDude assignment requirements and focuses on practicing Flexbox-based layouts, form styling, and CSS design principles.
